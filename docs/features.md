# 機能の詳細

README.md から移動した機能の詳細。

## Gyazo へのアップロード

拡大表示の「Gyazo にアップロード」で表示中の画像を Gyazo にアップロードし、ボタンの下に URL を表示する(同じ画像は同じ URL になるので通常は 1 件)。⚙ 設定の「Gyazo アクセストークン」(Gyazo API のアクセストークン)を入力する。この端末の localStorage にだけ保存。

## imgur へのアップロード

拡大表示の下部(メモ欄から離した位置)にある「imgur にアップロード」で、表示中の画像を imgur に匿名アップロードし、`i.imgur.com` の URL をクリップボードにコピーする(gif 可、mp4 は非対応、gif 以外は 20MB まで)。

- 初回は ⚙ 設定の「imgur Client-ID」に、https://api.imgur.com/oauth2/addclient で登録した Anonymous 用アプリの Client-ID を入力する(この端末の localStorage にだけ保存。リポジトリには含まれない)。

## 暗号化した画像(🔒)

Dropbox の `/index/crypto.json` があるとヘッダに 🔒 が出る。パスフレーズを入れると `/index/protected.bin`(暗号化した一覧)と `/protected/` の画像を `crypto.js`(WebCrypto: PBKDF2-SHA256 → AES-256-GCM)で復号し、通常の一覧に混ぜて検索・表示する。導出した鍵は取り出し不可の CryptoKey として端末の IndexedDB に保存(次回から入力不要)。🔓 でロック。ヘッダーのボタンは、ロック中は 🔒(通常色)、開錠中は 🔓(アクセント色の背景)で見分ける。一覧では暗号化した画像のタイルに、左上の 🔒 バッジとアクセント色の枠を付ける(gyazo-tycoon 本体のバッジに合わせた位置)。復号した画像・サムネイルはキャッシュに保存せずメモリのみ。暗号化した画像は imgur アップロード不可。形式は gyazo-tycoon の `seal.py` を参照。

## 起動時の一覧の読み込み

- `/index/manifest.json` の月ごとに `/index/YYYY-MM.json` を新しい月から6本並列で取り、先頭から途切れず読めた分だけ一覧の末尾に足す。読み込み中でもスクロールで継ぎ足せる(画面3つ分先まで。画像の読み込みは待たない)。
- 月別の一覧は Cache Storage(`gt-index-v1`)にキー `/__idx/<月>.<hash>` で残し、manifest の hash が同じ月は取りに行かない(古い版は消す)。画像キャッシュの上限・⚙「削除」の対象外。
- 並び順が新しい順以外(古い順・最近開いた順・閲覧数順)は、読み込みが終わるまで「読み込み中…」を出す。検索語は読み込み済みの分に対して効き、月が増えるたびに結果が増える。
- サムネイルは3本まで並列(25枚ずつ)で、画面に近い順に取る。画面から遠く外れたものは取らず、近づいたときに取り直す。429 は4秒待って3回まで取り直す。

## メモ

- 拡大表示を開くと、説明欄に最初からメモのテキストボックスが出る(「編集」ボタンは無い。gyazo-tycoon と同じ)。入力から抜けたら保存する。PC では Esc でも抜けられる(拡大表示は閉じない。もう一度 Esc で閉じる)。⌘/Ctrl+Enter でも保存する。
- 入力中に次の画像へ移る・閉じる場合も、その画像のメモとして保存する。入力中は ←→ で画像を切り替えない。
- 保存先はこの端末の localStorage だけ。⚙「閲覧履歴・メモを書き出す」で Mac へ渡し、反映されると端末側の控えは消える(テキストボックスの上に「この端末で編集済み・Mac へ未反映」と出る)。メモは検索の対象。

## ヘッダーと検索フォーム

- ヘッダーは「絞り込み・並び順・⬇️・🔀・🔒・⚙」を1行に収める(幅が足りないときは2つのセレクトが縮む。🔒 は暗号化の設定があるときだけ出る)。横スクロールは出さない。
- 種類フィルタは「全て / Gifアニメのみ / 暗号化のみ」(「暗号化のみ」は暗号化の設定があるときだけ選べる。ロック中に選ぶと空になり、開錠を促す文言を出す。静止 gif だけの選択肢は無い)。アニメは一覧の `am`(1=複数フレームの gif)で絞る。`am` は gyazo-tycoon 本体の `export_static.py` が `images.animated=1` の行に付ける。`animated` が未判定(NULL)の gif や、本体で `export_static.py --go` を流し直す前の一覧には `am` が無く、アニメ絞り込みに出ない。`a`(動くサムネの有無)とは別物で、静止 gif にも動くサムネ(a=1)は作られるため判定には使えない。
- 検索フォームは画面下(フッター)に張り付く。高さは CSS 変数 `--fh` に入れて、件数のステータスバー・本文の下余白・年月ラベルの下端がこれを避ける。iOS でキーボードが出たときは、`visualViewport` の分だけフッターを持ち上げる。

## 検索の正規化(OCR の取りこぼし対策)

検索語と検索対象(説明・タイトル・OCR 本文・メモ・URL・日付)の両側に同じ変換をかけて比べる(`index.html` の `normSearch`)。表示する本文は加工しない。本体のデータも変えないので、既存の一覧・暗号化画像(🔒)にもそのまま効く。
- NFKC(全角半角・互換文字)と小文字化。
- 日本語(非ASCII)に隣接する空白・改行を詰める。OCR が紙面の都合で「クラス メー⏎ト」と区切っても「クラスメート」で当たる。英語どうしの語間は詰めない(`a b` は `ab` で当たらない)。
- OCR が取り違えやすい文字の同一視。長音と各種ダッシュ(`ー − ‐ ―` と ASCII の `-`。漢数字の `一` は含めない)、カ/力・ロ/口・ニ/二・エ/工・ト/卜・タ/夕・ハ/八、ヘ/へ・ベ/べ・ペ/ぺ、ソ/ン、ツ/シ、小書き仮名と大書き(ッ/ツ、ャ/ヤ など)。足す・外すは `FOLD` の表だけ。
- 項目ごとに正規化してからつなぐので、タイトルの末尾と本文の先頭がつながって当たることはない。
- 入れていない: 0/O・1/l/I のような英数字の同一視(`10` が `lo` に当たるなど、短い検索語で誤ヒットが増えるため)、ひらがな⇔カタカナ全体の同一視。

## 月見出しと年月ラベル

- 並び順が新しい順・古い順のときだけ、一覧に「2026年10月」のような月見出しを入れる(最近開いた順・閲覧数順では出さない)。
- スクロールすると右端に年月ラベルが出て、スクロール位置に連動して動く。ドラッグすると月単位で飛べる(gyazo-tycoon の一覧と同じ)。PC ではマウスを右端に寄せても出る。
- 一覧は手元にすべてあるので、未描画の月へ飛ぶときは見出しの先まで描画してから移動する(離したときに飛ぶ。描画済みの月はドラッグ中にその場で動く)。読み込み中は読めた月だけが対象。

## 日付からの一覧ジャンプ

拡大表示の日付(一番上の行)はリンクで、押すと検索語と種類フィルタ(全て)を外し、一覧のその画像の位置までスクロールして一瞬枠を光らせる(gyazo の「アップロード日→一覧へジャンプ」と同じ)。絞り込みで見つけた画像の前後にアップロードした画像を見るのに使う。
- 並び順が古い順ならそのまま、最近開いた順・閲覧数順は新しい順に戻す(日付順でないと「前後」にならないため)。読み込み中は新しい順しか出せないので、古い順も新しい順に戻す。
- 種類フィルタ・並び順の変更は、セレクトを手で変えたときと同じく端末に保存される(次回起動もそのまま)。🔀 ランダムジャンプで開いた画像からも使える。

## オフライン

hateb-tycoon / scrapbox-tycoon と同じ方式。通信できなくても、ページは開き、一覧は出て、検索できる。

- **アプリ本体**: `sw.js`(Service Worker)が `index.html` / `crypto.js` / `build-info.js` / `favicon.png` を端末に残す。まずネットワーク、失敗または6秒たっても返らなければ前回のキャッシュ。Dropbox・imgur・Gyazo への通信は素通し。デプロイ時に `__BUILD_SHA__` がビルドのSHAに置換される(.github/workflows/deploy-pages.yml)。
- **一覧**: `/index/manifest.json`・月別の一覧・`/index/crypto.json`・`/index/protected.bin`(暗号文のまま)を `gt-index-v1` に控える。通信できない・8秒たっても返らない・429/5xx のときは、控えた一覧で起動する。月別の一覧は hash 違いの古い版でも使う。検索は読み込み済みの一覧に対してメモリ上で行うので、オフラインでもそのまま効く。
- **画像**: 端末キャッシュ(⬇️ の先読み・一度見たもの)にあるサムネイル・原寸・動くサムネイルは表示される。キャッシュに無いものは空欄/読み込み失敗のまま。
- **表示**: 控えの一覧で開いているとき、件数の横に「· オフライン」と出る。オンラインに戻ると、拡大表示・検索・設定を開いていなければ自動で読み直す。
- **初回**: 一度もオンラインで開いていない端末では何も無いので、「オフラインです」と出る。ホーム画面に追加して、オンラインで一度開いておく。
- **暗号化した画像(🔒)**: 一覧(検索対象)は控えがあれば出る。パスフレーズ(の鍵)は IndexedDB にあるので、入力不要のままオフラインでも開く。サムネイル・原寸は復号後をキャッシュしない方針のため、オフラインでは見られない。

## 端末キャッシュと先読み(⬇️)

- サムネイル・原寸・動くサムネイルは端末の Cache Storage に残る。量は ⚙ の「保持する上限(MB。既定 3000)」で管理し、超えたら原寸→古い順に捨てる(サイズの控えは IndexedDB `gt_cache`)。
- ヘッダの ⬇️(🔀 の左)を **Wi-Fi のときに手で押す**と先読みする(iOS Safari は接続種別を取れず、バックグラウンド実行もできないので、画面を開いたままにする)。もう一度押すと中断。進捗は画面右下のステータスに出る。
  1. サムネイルを新しい順に(上限の4割まで)
  2. 閲覧数の多い順に原寸(Mac が書く `/index/hot.json` + この端末の閲覧履歴)。上限に達したら止まる
- 暗号化した画像(🔒)と mp4 は先読みしない。429(レート制限)は待って取り直す。
- 件数(「N枚」)は画面右下のステータスバーに表示する。
