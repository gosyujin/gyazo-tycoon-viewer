# 技術的な注意点・不変条件・既知の制限・未実装・未検証

README.md から移動した注意事項。

## 既知の制限

- 応答の deletehash は画像ごとに localStorage に残り、拡大表示の「imgur から削除」で消せる。匿名アップロードは imgur 側に管理画面がないので、この端末以外からは消せない。
- 同じ画像を再度アップロードしても重複チェックはしない。
- iOS はタブのままだと7日触らないとサイトデータを消すことがある。ホーム画面に追加して使うと残りやすい。

## 未検証

- 起動時の一覧の並列読み込み・端末キャッシュ(`gt-index-v1`)・サムネ3本並列は、模擬の Dropbox(遅延つき)でだけ確認した。実機の iOS Safari での体感と、Dropbox の 429 が増えないか(月別6本・サムネ3本の並列)は未確認。
